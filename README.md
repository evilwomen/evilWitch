## 补充：司法实践中的“欺诈性抚养”

法院公开材料通常将“欺诈性抚养”概括为：婚姻关系存续期间，一方明知或应知所生子女并非配偶亲生，却故意隐瞒相关事实，使配偶误认为系亲生子女并承担抚养义务。司法实践中常见救济包括：

- 确认或否认亲子关系；
- 请求返还不应承担的抚养费、医疗费等实际支出；
- 在存在相应过错和精神损害的案件中请求精神损害赔偿；
- 特定案件中还可能涉及离婚财产协议、财产重新分配或撤销等争议。
